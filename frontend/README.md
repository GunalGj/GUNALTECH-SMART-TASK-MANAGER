# GUNALTECH Smart Task Manager — Frontend

A responsive HTML, CSS, and vanilla JavaScript dashboard starter for the GUNALTECH Smart Task Management System.

## Run locally

1. Open the `frontend` folder.
2. Open `index.html` in a modern browser. For a local development server, use the VS Code Live Server extension.

## Included in this starter

- Responsive workspace dashboard layout
- Task summary cards
- Recent task list with search and status filter
- Create-task dialog
- Mark tasks complete / reopen them
- Project progress and team preview

## Current limitations

This is a frontend-only prototype. Tasks are held in browser memory and reset on refresh. Authentication, role-based Admin / Employee / Customer dashboards, API integration, persistent storage, and the Spring Boot + MySQL backend will be added in later stages.
